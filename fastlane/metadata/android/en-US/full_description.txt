IBAN Registry is a simple offline app for keeping IBAN bank account details
organized on your Android device.

Features:

* Add an IBAN with a useful description
* Validate country-specific IBAN length and checksum
* Reject duplicate accounts
* Search by IBAN or description
* Organize accounts with folders and tags
* Rearrange accounts in a custom order
* Export and import backups with Android's document picker
* Edit and delete saved accounts
* Copy an IBAN to the system clipboard

All records remain in the app's private on-device database. The app has no
network permission, analytics, advertising, tracking, or bank integrations.
Android backup is disabled so saved IBANs are not included in device backups.
