# Privacy policy

IBAN Registry works entirely offline.

## Data handled by the app

The app stores the IBANs and descriptions entered by the user in a private
database on the Android device. This information is used only to display and
manage the user's saved accounts.

## Data sharing and collection

IBAN Registry:

- does not collect analytics or diagnostics;
- does not contain advertising or tracking SDKs;
- does not request network access;
- does not send data to the developer or any third party;
- does not access bank accounts, balances, contacts, or payment services.

When the user chooses **Copy IBAN**, the selected IBAN is placed on Android's
system clipboard. Other software with clipboard access may be able to read it,
subject to Android's platform protections.

## Storage and deletion

Android stores the database in the app's private storage. Android backup is
disabled for this app. Individual records can be deleted within the app. All
remaining app data can be deleted by clearing the app's storage or uninstalling
the app.

## Changes

Material changes to this policy will be documented with an app release.
